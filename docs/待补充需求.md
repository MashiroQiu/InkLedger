# 墨账：待补充界面与规则

以下“第一版暂定”均是可修改的实现约定，并非已经得到你确认的最终需求。

| 项目 | 第一版暂定 | 需要你补充 |
|---|---|---|
| 回收站 | 侧边栏与设置提供入口；按当前账本显示；不自动清理；单笔恢复／确认永久删除 | 留存 7／30／90 天或永久？是否需要整天恢复、批量恢复、清空、临到期提醒？ |
| 长按手势 | 已实现按压位置菜单：编辑／删除／多选；多选支持全选、分类及删除 | 是否还需要复制、拖动排序或其他批量操作？ |
| 记一笔 | 收入／支出、分类、金额、备注、日期、时间；点击保存后关闭 | 是否需要数字键盘、计算器、连续记账、账户、成员、商家、标签、地点、图片、语音？ |
| 账单详情 | 半屏详情、编辑、移入回收站；平板侧栏不受遮罩影响 | 是否需要分享、复制、附件预览、操作历史、关联退款、展开全屏？ |
| 分类 | 内置分类与自定义新增／改名；最多 10 字符宽度；通用线条图标 | 是否需要自选图标、二级分类、排序、合并、停用、删除及历史账单迁移规则？ |
| 账本管理 | 创建、切换，不自动关联账户；预算各自独立 | 重命名、封面、归档、删除、默认账本、多人协作、账本独立币种？ |
| 账号与同步 | 仅本地使用者，未接入后台 | 登录方式、是否允许游客、云存储服务、冲突合并、注销与数据删除规则？ |
| 账户与资产 | 尚未实现现金／银行卡等资产管理 | 支付账户、账户余额、转账、信用卡、借贷、投资资产、余额校准如何设计？ |
| 特殊账单 | 仅收入／支出 | 退款是收入还是冲减原支出？转账是否计入收支？报销、分期、优惠、手续费、欠款怎样计算？ |
| 金额与币种 | 人民币、分单位存储、展示两位小数 | 多币种、汇率来源、金额上限、千位分隔、隐藏金额、负金额输入？ |
| 合计预算 | 每期独立设置，不自动与分类预算同步 | 是否允许结转、模板复制、自动续期、按收入比例预算、额度超支提醒？ |
| 分类预算 | 支出分类可设置独立额度；各分类额度相加得到“分类预算合计” | 父子分类额度如何合并？未设预算分类如何处理？是否支持每日额度？ |
| 预算趋势 | 对当前账单按日期重算累计趋势；未来日期不绘制 | 是账单重算，还是历史每日快照？调整预算后，历史余量是否回溯改变？未来线是否延展？是否支持点击查看每天数据？ |
| 年度账单中的月预算 | 所选年份＋设备当前月份 | 年度账单界面是否强制展示年度预算，或允许单独指定月份？ |
| 统计 | 选择月份／年份，收支结余与支出分类构成 | 同比／环比、账户／成员／商家／标签统计、日历、排行、收入构成、统计排除项？ |
| 搜索 | 当前账本、当前所选期间；分类、备注、金额文字匹配 | 是否默认搜索全部年份？金额区间、分类、账户、日期、收支组合筛选？ |
| 备份导入导出 | 完整 JSON 备份；校验后确认替换；本地系统文件选择器 | 是否支持 Excel／CSV、钱迹格式、增量合并、加密备份、自动备份、WebDAV？ |
| 自动记账 | 尚未实现 | 是否需要无障碍支付识别、通知识别、剪贴板识别？支持哪些支付应用，如何确认识别结果？ |
| 提醒与重复账单 | 尚未实现 | 每日提醒时间、周期收入／支出、到期提醒、预算阈值提醒？ |
| 视觉配色 | 主界面灰阶，收支与趋势使用你指定的红绿 | 是否提供“全灰阶模式”？深色模式、金额红绿反转、字体大小是否需要？ |
| 动效 | 强／均衡／弱材质；条目／整天粒子消散；触摸阻尼回弹 | “全局粒子”是否还指点按、导航、保存、切换账本等场景？强弱档是否同时影响回弹与粒子数量？ |
| 平板与折叠屏 | 宽度 ≥840 CSS px 常驻侧栏，横竖屏随可用宽度切换；侧栏可收起 | 是否希望平板竖屏仍强制常驻？折叠屏阈值、窗口尺寸、双栏详情和键盘快捷键？ |
| 隐私与安全 | 无网络权限，应用私有原子文件；手动导出 | 密码锁、指纹、截图保护、数据库加密、隐私政策与解锁超时？ |
| 无障碍 | 按钮文字、焦点提示、弹层焦点约束、减少动态效果 | TalkBack、放大字体、对比度、色觉辅助目标？ |
| 产品与发布 | 暂名“墨账”，调试签名 0.1.0；Android 8+、需现代 WebView | 正式名称／图标、包名、最低系统、是否要求纯原生 Compose、正式签名、发布渠道与目标设备？ |

灰阶暂定值：白色 `#FFFFFF`、浅灰色 `#F0F0F0`、浅中灰色 `#DEDEDE`、中灰色 `#888888`、中深灰色 `#555555`、深灰色 `#333333`、黑色 `#000000`。

建议优先补充：回收站期限与批量操作、记一笔的字段与键盘、账户和特殊账单计算规则、预算历史快照规则、是否要求纯原生 UI、账号同步范围。
